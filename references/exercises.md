# Exercise options

Choose the exercise to match the aim, ground and group. Do not make an exercise harder merely by adding distance.

| Exercise | Participant instruction | Coach setup |
|---|---|---|
| Draw | Draw your route before you go. | Full map and pencil. Review the main features. |
| Sketch | Draw only the features you need. | Separate paper. Carry a folded full-map backup. |
| Memory | Read the next leg. Fold the map, then go. | Short legs; reopen the map whenever needed. |
| Star | One control, then back. | Several destinations around a shared base. |
| Loop | Visit the controls in order. | Return to a shared base between loops. |
| Three words | Say three key words, then fold the map. | One point per clean leg without another look. Time breaks ties. |
| Pairs relay | Run, tag, swap. | Two loops. Each runner does both; keep total distance per runner within the brief. |
| Score | Choose the order. Return on time. | Clear time limit, points and late rule. Use codes without connecting lines. |
| Harder legs | Pick an attack point. Commit to the plan. | Use contour, rock or vegetation detail with a clear stopping feature. |
| Plain map | No instruction needed. | Preserve scale, north and credits; omit course markings. |

For a range of abilities, vary leg length, number of decisions and feature difficulty. Keep some very short options. Prefer a few purposeful controls to many arbitrary ones.

For memory and sketch work, never remove the option to use a full map if lost. Route simplification means choosing useful detail, not hiding hazards or restrictions.

Host notes should fit the task: setup, timing, boundaries, return time, control list and collection. Use current club procedures for the formal risk assessment and consent arrangements.
